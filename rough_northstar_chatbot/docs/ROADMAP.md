
# ROADMAP.md
# NorthStar AI Customer Support Chatbot
## Product Evolution Roadmap

Version: 1.0

## Current Scope (Assignment)
- Offline Streamlit application
- Semantic intent recognition (MiniLM)
- SQLite repository
- Order tracking
- Returns
- Shipping information
- Product recommendations
- Human handoff simulation

## Phase 1 – Production Foundation
- PostgreSQL adapter
- Environment configuration
- Docker support
- Structured logging
- Configuration profiles

## Phase 2 – API Layer
- FastAPI REST service
- Authentication
- Rate limiting
- OpenAPI documentation

## Phase 3 – AI Improvements
- Retrieval-Augmented Generation
- Local LLM (optional)
- Vector database
- Better recommendation engine

## Phase 4 – Enterprise
- OMS/ERP integration
- CRM integration
- Admin dashboard
- Analytics
- Monitoring

## Long-Term Goals
- Multi-language support
- Voice interface
- Multi-channel (Web, WhatsApp, Teams)
- Personalized recommendations

## Guiding Principle
Maintain the layered architecture and repository abstraction while evolving features.
