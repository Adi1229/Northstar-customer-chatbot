As a freelancer in the simulated project, you will build a functional customer support chatbot that
could be used by a small e-commerce business specializing in outdoor apparel and camping
gear.
All required business context, data, and requirements are provided below.
1. Brand Persona
a. Name: North Star Support Bot (or similar)
b. Tone: friendly, helpful, outdoorsy, concise
c. Audience: North American outdoor consumers
2. Core Use Cases (required)
a. The chatbot must handle:
i. Order Tracking
1. Ask for order number
2. Return simulated status
ii. Return & Exchanges
1. Explain return policy
2. Provide returns link
iii. Product Recommendations
1. Ask 1-2 clarifying questions
2. Recommend product category
iv. Human Handoff
1. Handle fallback or explicit request
2. Transition to “Live Agent” state
3. Functional Requirements
a. Intent Recognition
i. Handle variations (e.g., “Where is my order?” vs. “Track my package”)
b. Conversation Flow
i. Logical, guided interactions
ii. Return user to main flow after resolution
c. Mock Order Handling
i. Use the following order status information exactly as provided:
1. Order #111 -> Shipped, arriving tomorrow
2. Order #222 -> Processing, ships in 24 hours
3. Order #333 -> Delivered (ask follow-up if needed)
4. Any other order -> invalid order
d. Customer Support Information
i. Your chatbot must accurately provide the following information when
responding to customer inquiries:
1. Return Policy
a. 30-day returns
b. Items must be unused
c. Original packaging required
2. Shipping Information:

a. Standard shipping: 3-5 business days
b. Expedited shipping: 1-2 business days
e. Human Handoff
i. When a user requests a live agent or reaches a fallback scenario, the
chatbot must:
1. Transition the user to a simulated Live Agent state
2. Clearly communicate the handoff
3. Allow the user to return to the main menu or continue interacting
with the chatbot after the handoff
ii. Fallback Handling
1. Clear “I didn’t understand” response
2. Offer options or escalation
4. Provided Materials
a. Return Policy: 30-day returns, unused items, original packaging
b. Shipping:
i. Standard: 3-5 days
ii. Expedited: 1-2 days

d. Keep implementation practical and testable

c. Accuracy of responses based on provided data
